хочу написать новый скриптовый язык:

- автоматизация типовых задач на десктопе
- вместо типового shell на Linux
- REPL для микроконтроллеров

## зачем

> скриптовый язык общего назначения для автоматизации типовых задач на десктопе, вместо типового shell на Linux

типовые задачи в порядке уменьшения приоритета:

- разработка ПО для embedded Linux и микроконтроллеров (Cortex-M, ESP)
- проектирование печатных плат, расчёт схем
- разработка сборок и отдельных конструктивных элементов (фрезеровка, токарка и 3D печать)
- создание игр
- проектирование одежды
- работа с MIDI-клавиатурой (создание музыки, обучение игре)

## для кого

личное применение

## синтаксис

> определяемый и расширяемый пользователем

базовый язык форт-подобный, но позволяет пользователю определять собствzнные произвольные языки, используя встроенные средства декларативного определения лексических и синтаксических анализаторов

## архитектура

- интерпретатор байт-кода + REPL
- ядро (языковая VM) реализовано на ограниченном С++ для микроконтроллеров, но по умолчанию собирается под десктопный и embedded Linux; REPL со встроенным инкрементным компилятором байт-кода реализовано на flex/bison/libreadline; одновременно в проект включена зеркальная реализация на Rust
